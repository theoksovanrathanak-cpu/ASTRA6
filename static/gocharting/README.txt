@gocharting/chart-sdk 1.0.71 (webpack / UMD build)

Installed via the official CLI against GoCharting's protected registry:
  npx -p @gocharting/cli gocharting install @gocharting/chart-sdk@webpack
  (SDK key: demo key published in GoChartingOSS/gocharting-sdk-examples README)

License: COMMERCIAL. Free tier while the GoCharting attribution stays visible.
For production, request a licence credential at https://gocharting.com/sdk/docs
and set GOCHARTING_LICENCE_KEY in the environment.

Files served from this folder:
  index.umd.js   - the SDK bundle (exposes window.GoChartingSDK)
  vendor/*.js    - lazily fetched catalog/icon chunks (required, keep them)
  locales/*.json - translations
